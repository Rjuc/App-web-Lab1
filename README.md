# Laboratorio de JavaScript y AJAX

En esta página reuní los cuatro ejercicios de JavaScript y la consulta AJAX del laboratorio. Los colores elegidos recuerdan los tonos de un bajod e la serie Yamaha por simple gusto personal. Los enlaces de «Siguiente ejercicio» conectan una sección con la siguiente mediante anclas.

La página está publicada en [GitHub Pages](https://rjuc.github.io/App-web-Lab1/). La estructura está en `index.html`, los estilos en `styles.css` y la lógica en `app.js`. La consulta AJAX usa `XMLHttpRequest`; para leer una respuesta de otro sitio, ese servidor debe permitir el acceso mediante CORS.
